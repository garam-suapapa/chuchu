# 수영복 투명화 및 프레임 검수

사용자의 로컬 이미지 후처리 승인 이후 Pillow와 numpy로 처리했습니다. 추가 image_gen, API, CLI 생성 및 패키지 설치 없이 원본을 보존했습니다.

## 최종 파일

- `processed/bangulping_outfit_09-worn.png`: 600 × 700 RGBA, alpha 범위 0–255, 완전 투명 픽셀 234,536개. alpha > 8 경계 `(48,25,551,667)`.
- `processed/bangulping_outfit_09.png`: 512 × 512 RGBA, alpha 범위 0–255, 완전 투명 픽셀 111,640개. alpha > 8 경계 `(31,20,480,492)`.
- 두 파일 모두 캔버스 네 가장자리의 최대 alpha 0. 전체 머리, 양갈래 끝, 손, 발, 소매, 바지단 잘림 없음.
- 기존 원본·상위 디렉터리의 첫 생성 파일을 덮어쓰지 않았습니다. 사용 시 `processed/` 파일을 참조해야 합니다.

## 처리 방법 및 재현

`process_09.py`를 Pillow/numpy 사용 가능한 Python으로 실행합니다. 각 원본에서 밝고 중성적인 RGB 후보(max-min ≤ 15, min ≥ 219) 중 캔버스 바깥과 연결된 영역만 제거하여 내부의 눈 흰자·하이라이트와 크림 옷을 보존합니다. 패딩한 마스크에서 Pillow flood fill을 사용합니다. 가장자리에 0.4px alpha blur를 적용하고 Lanczos로 축소합니다.

착용본은 피사체의 alpha > 8 경계로 crop 후 기존 reference의 `(48,21,551,671)` 503 × 650 영역 안에 비율을 유지하여 가운데 배치했습니다. 선택용은 512 × 512에 최소 20px 여백을 유지했습니다.

## 육안 검수

`09-qa-worn-contact.png` 및 `09-qa-sprite-contact.png`를 view_image로 열어 연회색·짙은 보라·마젠타·초록 네 배경에서 확인했습니다.

- 바깥 체크무늬와 착용본 다리 사이, 선택용 바지 사이 배경이 제거됨.
- 얼굴, 눈 하이라이트, 크림 앞판과 단 처리, 금색 별, 머리 하이라이트 보존됨.
- 선택용에는 신체·손·얼굴·머리·마네킹 없음. 착용본과 디자인 일치.
- 큰 배경 잔여물, 투명 구멍, 잘린 실루엣 없음.
- 생성 원본에 내재된 캐릭터 비율 차이는 유지됨. 얼굴과 자세가 원본 픽셀과 동일한 합성은 아님. 극확대 시 안티앨리어싱 가장자리의 미세한 밝은 윤곽은 남을 수 있으나 runtime 크기의 네 대비색 검수에서는 큰 halo가 보이지 않음.

기계 측정값은 `09-qa.json`에 기록했습니다. 생성 프롬프트 및 실패했던 원본 투명화 이력은 상위 `09-notes.md`에 있습니다.
