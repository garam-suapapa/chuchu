# 하츄핑 보정본 검수 — 2026-09-07

사용자가 Python 등의 로컬 배경 제거와 크기 조정을 명시 승인한 이후 처리했습니다. 기존 생성 원본 및 과거 RGB/투명화 실패 기록은 그대로 보존했습니다.

## 결과

- 4벌 × 2개 = **8개 투명 RGBA PNG**.
- `processed/{pajamas,raincoat,swimwear,winter}/worn.png`: 600×700.
- `processed/{pajamas,raincoat,swimwear,winter}/sprite.png`: 512×512.
- 모든 캔버스 가장자리 alpha=0, 모든 결과에 alpha=0과 alpha=255 및 부드러운 중간 알파 존재.
- 원본 8개 SHA-256은 이전 `validation.json`과 전부 일치.
- 카탈로그 4개 모두 `runtimeReady:true`, `status:processed-review`.
- `source-catalog.json`과 원래 각 폴더의 metadata/prompts는 보정 전 기록입니다.
- `processed/qa.json`에 파일별 치수, 알파 경계, 원본·결과 SHA-256, 투명 픽셀 수 기록.

## 방법

밝은 무채색 픽셀 중 외부 배경과 연결된 영역을 분리했습니다. 눈동자 하이라이트와 의상 내부의 흰 장식처럼 닫힌 밝은 영역은 보존했습니다. 전신의 다리 사이 좁은 무채색 배경 성분은 위치와 크기를 확인하여 제거했습니다. 100픽셀 이하 배경 잡티를 제거하고 0.55픽셀 가장자리 안티앨리어싱과 2픽셀 이내 경계 색 오염 보정을 적용했습니다. 원본 캐릭터의 내부 RGB는 재생성하지 않았습니다.

수영복 착용본의 왼쪽 귀에는 배경과 이어지는 매우 옅은 하이라이트가 있어 단순 색상 분리 시 귀가 패였습니다. 원본의 해당 귀 영역 (205,70)–(425,280)에서 보존된 윤곽의 convex hull로 알파만 복원했습니다. 원본 귀의 RGB를 사용했으며 귀를 새로 그리거나 다른 착용본으로 대체하지 않았습니다.

## 배치

기존 `reference-wearables/hachuping/hachuping_outfit_01-v12/worn.png`의 alpha>128 경계 (77,27)–(527,661)를 사용했습니다. alpha>0 경계에는 캔버스 바깥쪽 잡픽셀이 있으므로 사용하지 않았습니다. 새 전경 알파 경계를 자른 후 높이 634픽셀로 균등 축소하고 중심 x=302, 머리 y≈27, 발끝 y=660에 맞췄습니다. 단순 원본 캔버스 축소는 사용하지 않았습니다.

최종 alpha>128 경계:
- 잠옷: (70,27)–(534,661)
- 우비: (86,27)–(517,661)
- 수영복: (66,27)–(537,661)
- 겨울옷: (64,28)–(539,661)

선택본은 실제 옷 경계에 맞춰 자르고 512×512 캔버스에 최소 20픽셀 여백을 넣어 가운데 배치했습니다.

## 육안 검수

`contact-sheet.png`의 짙은 청록색·주황색 배경 16개 패널을 view_image로 검수했습니다. 추가로 실제 600×700 착용본을 확대 확인했습니다.

- 전체 머리·팔·모은 손·다리·신발 및 의상 끝 잘림 없음.
- 체크무늬 잔상이나 큰 배경 조각이 보이지 않음.
- 눈의 흰 반사광, 겨울옷의 크림색 털, 잠옷의 크림색 파이핑, 우비의 광택 보존.
- 팔/머리 사이 빈 공간과 분리된 다리 사이 배경 제거.
- 수영복 귀의 하이라이트와 외곽 복구 확인.
- 선택본에 손·신체 없음, 착용본과 디자인 일치.

한계: 생성 단계의 눈/턱/머리 비율은 기존 reference와 픽셀 단위로 같지 않습니다. 비율 유지 배치로 머리/발 높이를 맞췄으며 기존 액세서리와의 앱 내 조합 검수는 상위 통합 단계에서 수행할 수 있습니다.

## 재현

Python에 Pillow, numpy, scipy가 필요합니다. 이 작업에서는 번들 Python의 해당 라이브러리를 사용했고 모델/API/재생성은 사용하지 않았습니다. 저장소 루트에서 실행:

```powershell
python assets/runtime/expansion/outfits/hachuping/process-assets.py
# 생성된 contact-sheet.png를 육안 확인한 후:
python assets/runtime/expansion/outfits/hachuping/finalize-processed.py
```

첫 스크립트는 배경제거·규격변환·대비 접촉판과 기본 QA를 재현합니다. 두 번째 스크립트는 원본 해시, RGBA, 전체 투명 테두리, 치수, 머리/발 높이를 assert로 검사하고 검수 승인된 카탈로그를 갱신합니다.
