# Winter outfit local post-processing QA

The user explicitly approved local image post-processing after the image generator returned opaque checkerboard PNGs. All original generated PNG files are unchanged. Only this processed directory contains the new derived assets.

## Result
- `bangulping_outfit_10-worn.png`: actual RGBA PNG, 600×700. Alpha >8 bounding box is (55,21,543,671). The source silhouette was cropped, fitted proportionally into the requested 503×650 reference region anchored at (48,21), and centered. No stretching or clipped hair, feet, coat or hands.
- `bangulping_outfit_10.png`: actual RGBA PNG, 512×512. Alpha >8 bounding box is (27,20,484,492); requested minimum 20-pixel margin is preserved. Only clothing is present.
- Full canvas edge alpha is zero for both outputs. Counts, source dimensions and original SHA256 values are in `10-qa.json`.

## Method and reproduction
Run `process_10.py` with Python and Pillow/numpy. It reads the unmodified originals from the parent directory. It removes bright neutral checkerboard pixels only when connected to the exterior, using warmth to distinguish cream fur. Interior face, hair and fur highlights are preserved. A small explicit region between the legs removes checkerboard cells disconnected by source antialiasing, with fractional alpha and light-background color unmatting to reduce white contamination. It then uses alpha-aware Lanczos scaling and transparent padding.

No extra model generation, paid API calls or new dependency installation was used for this stage.
