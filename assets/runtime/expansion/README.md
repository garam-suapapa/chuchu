# 추가 에셋 제작

목표: 배경 4종, 악세서리 6종, 의상 16벌(캐릭터별 4벌), 소품 6종 추가.

2026-09-07 제작과 로컬 보정을 완료했다. 추가 32종은 배경 4종, 악세서리 6종, 의상 16벌, 소품 6종이며, 의상의 선택용/착용용을 각각 포함하면 게임용 이미지 48개다. `runtime-audit.json`에서 목록·파일·PNG 규격 검사를 확인할 수 있다. `source-audit.json`은 보정 전의 원본 제작 단계 기록이다.

기존 에셋을 덮어쓰지 않고 이 디렉터리에 저장한다. 각 제작 폴더의 `catalog.json`이 목록이며 `prompts.md`에 실제 제작 프롬프트를 기록한다. 이미지 제작은 built-in image_gen, 사용자 허용 후의 배경 제거와 크기 조정은 로컬 Python(Pillow·NumPy·SciPy)을 사용했다. 생성 원본은 보존하고 투명 보정본은 각 종류·캐릭터의 `processed/`에 저장했다.

## 검수

- 배경은 전체 화면을 채우는 불투명 이미지이며 인형을 놓을 중앙 바닥 공간을 확보한다.
- 악세서리·소품·의상은 실제 투명 알파가 필요하다. 흰색 또는 체크무늬가 그려진 RGB 이미지는 투명 PNG가 아니다.
- 의상은 몸이 없는 선택용 옷 이미지와 600×700 완성 착용 이미지가 모두 필요하다.
- 생성된 후보와 게임에서 쓸 수 있는 검수 완료본을 구분한다. 제작 완료만으로 사용자 시각 승인을 의미하지 않는다.

루트의 `asset-expansion-review.html`에서 보정본을 비교할 수 있다. `npm run verify:expansion`은 목표 수량, ID 중복, 경로, PNG 알파 형식과 착용 프레임을 검사한다. `python verify-expansion-images.py`는 실제 투명 픽셀·잘림·원본 해시를 검사하고 대비색 접촉판을 만든다(Pillow·NumPy 필요). `npm run test:expansion`은 로딩 실패 격리와 새 코디/위치/프리셋 저장 복원을 검사한다. 서버 실행 후 `npm run review:expansion`으로 실제 브라우저 검증을 재현한다(Playwright 필요).

## 게임 연결

배경 4종은 `decor-catalog.js`에 추가되어 총 8종을 고를 수 있다. `expansion-assets.js`는 각 카탈로그의 `runtimeReady: true` 항목을 읽어 기존 목록에 더한다. 현재 의상 40벌(캐릭터별 10벌), 악세서리 12종, 소품 9종(기존 3종+신규 선택 카드 6종)이 연결되어 있다. 새 의상 착용본은 모두 600×700이며 기존 캐릭터의 유효한 머리 꼭대기·발끝 경계에 맞춰 비율을 유지했다. 악세서리는 카탈로그의 캐릭터별 위치를 사용하고 직접 이동할 수 있다.

배경 8종의 실제 브라우저 선택, 새 배경 4종의 새로고침 후 저장 복원, 가로·세로 화면 및 콘솔/네트워크 오류 검사를 통과했다. 증거는 `artifacts/background-expansion-qa/report.json`과 같은 폴더의 스크린샷에 있다. 기존 프리셋 테스트 8개도 통과했다.

최종 통합 검증도 통과했다. 신규 의상 16벌 실제 착용, 캐릭터 4명×신규 악세서리 6종, 신규 소품 6종과 기존 3종, 코디·악세서리 이동 위치 저장 복원, 1200×900 사진 다운로드, 가로 1280×800·세로 800×1280 화면을 확인했다. 콘솔·HTTP 오류는 0건이다. `artifacts/expansion-final-review/report.json`에 결과가 있다. `artifacts/expansion-qa/image-report.json`은 이미지 48개 검사 및 원본 48개 해시 일치를 기록한다. 소품 원본은 최초 imagegen 캐시와도 대조했다(`props/generated-source-hashes.json`). 신규 테스트 6개와 기존 프리셋 테스트 8개가 통과했다.

초기 원본은 RGB 흰색/체크무늬 배경을 포함했고 image_gen 배경 추출도 알파를 반환하지 않았다. 로컬 보정으로 이 문제를 해결했다. 외곽과 연결된 중립색 배경을 제거하고, 장화·손잡이 사이의 닫힌 배경은 원본에서 확인한 위치로 분리했다. 흰 귀·겨울 털·진주 하이라이트는 별도로 보호했다. 각 폴더의 처리 스크립트와 QA 기록에 방법이 남아 있다. 생성 과정에서 생긴 얼굴·체형의 미세한 차이는 보존되어 있으므로 기술 검사 통과가 사용자 미술 승인을 의미하지는 않는다.
