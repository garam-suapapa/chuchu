# 잠옷 로컬 후처리 검수

사용자의 로컬 이미지 처리 승인 후 Pillow/numpy로 처리했다. 실제 생성 원본 두 파일은 변경하지 않았다.

- 밝고 무채색인 배경 후보 중 외부와 연결된 픽셀만 제거했다. 눈의 흰 부분, 머리 윤광, 크림 잠옷과 별은 보존했다.
- 원본 가장자리에 1px 마스크 축소 및 0.35px feather 적용 후 비율 유지 축소했다.
- 착용본은 실제 피사체 경계를 잘라 기존 reference의 alpha>8 경계 (48,21,551,671)에 맞춰 600×700 캔버스에 배치했다.
- 선택용은 512×512, 20px 최소 여백이다.
- `07-qa-worn.jpg`와 `07-qa-selection.jpg`를 view_image로 직접 확인했다. 남색/분홍/노랑 위에서 체크무늬 잔상 없음, 흰 의상 내부 과삭제 없음, 전체 머리/발/옷 잘림 없음, 바지 사이 투명 확인.
- 수치 검수는 `07-qa.json`, 종합 검수 및 원본 해시는 `qa-report.json`.

재현: `python assets/runtime/expansion/outfits/bangulping/processed/process_07.py` (Pillow/numpy).
