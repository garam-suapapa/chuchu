# 방울핑 후처리 완료본

사용자가 2026-09-07 Python 등 로컬 배경제거·크기 조정을 승인한 뒤 처리했다. 4벌/8개 PNG 모두 RGBA, 착용본 600×700, 선택용 512×512이다. 원래 생성 파일은 상위 폴더와 sources에 그대로 보존한다.

피사체만 자른 후 종횡비를 유지해 기존 `reference-wearables/bangulping/bangulping_outfit_01-v12/worn.png`의 alpha>8 경계 (48,21,551,671)에 contain 배치했다. 전체 불투명 원본 캔버스를 축소하는 방식이 아니다. 생성된 캐릭터 자체의 작은 얼굴/몸 비율 차이는 남아 있다.

밝은 무채색 후보와 외부 연결성을 이용해 배경을 제거했고, 고립된 눈/하이라이트 및 크림색 옷은 보호했다. 우비의 갇힌 다리 사이 배경은 검수된 국소 seed로 제거했고 겨울옷의 가느다란 다리 틈은 국소 matte를 보정했다. 도구 추가 생성이나 유료 API 호출 없이 Pillow/numpy만 사용했다.

모든 착용/선택 이미지를 어두운색 및 대비색 접촉판으로 직접 확인했다. 전체 실루엣과 선택옷이 프레임 안에 있으며 선택옷에 신체가 없다. 체커 잔상과 흰 의상/눈 과삭제는 보이지 않는다. 원본 8개 해시는 이전 `../qa-report.json`과 동일하다. 현재 검수는 이 폴더의 `qa-report.json`을 참조한다. 과거 RGB 실패 기록은 삭제하지 않았다.

## 재현

Python + Pillow + numpy에서 `process_07.py`, `process_08.py`, `process_09.py`, `process_10.py`를 각각 실행한다. 실행 디렉터리와 무관하게 스크립트 위치를 기준으로 원본과 출력 경로를 찾는다. 이후 `finalize.py`를 실행하면 원본 해시/PNG alpha/규격/여백을 검사하고 이 확장 폴더의 catalog.json만 갱신한다. app과 기존 game-assets.json은 변경하지 않는다.

통합에 필요한 최종 파일은 `bangulping_outfit_07.png`~`10.png`, 대응하는 `-worn.png` 4개, 상위 `catalog.json`이다. 검수판과 코드도 이 폴더에 함께 보관했다.
